# openPDKcreator: A General-Purpose Toolkit for Reading, Editing, and Round-Trip Exporting PDKs

A plain `article`-class LaTeX technical report describing this
project: its architecture, real-format coverage (KLayout layers,
Magic technology files, LEF, DRC decks, Liberty, GDS, netlists,
ngspice, xschem), the whole-PDK round-trip verification methodology,
and the user-defined Verilog/Verilog-A model extension. Single self-contained
`main.tex`, no bibliography or external figures.

Not compiled locally by design -- imported into Overleaf and compiled
there.

## Importing into Overleaf

Overleaf -> **New Project -> Upload Project** (zip `main.tex`), or
**Import from GitHub** if this repo is pushed there -- `main.tex` at
this directory is the main file either way.
